# OTTpaper 개발 계획 (웹 / GitHub Pages)

원안: 안드로이드 앱 계획서(OTT 허브). 개인 사용 + GitHub Pages 무료 호스팅에 맞춰 조정했다.

## 1. 원안 대비 조정

| 원안(안드로이드) | 웹 버전 |
|---|---|
| 설치된 앱 자동 감지 | 웹은 불가 → 설정에서 "내가 쓰는 OTT"를 직접 선택, 상세에서 우선 표시 |
| 앱 딥링크 실행 | 서비스 공식 사이트 링크 + TMDB 시청 페이지(JustWatch 제공) 링크 |
| Room / DataStore | localStorage (설정, 최근 검색/조회, API 응답 캐시) |
| WorkManager 신작 알림, 위젯, 음성 | 제외 (2차: 공개 예정 탭으로 대체, 음성은 Web Speech API 검토) |
| 서버 없음 | 서버 없음 (정적 사이트) |
| 수익 모델 | 없음 (개인용) |

## 2. 범위

포함(MVP): 통합 검색(영화/TV), 트렌딩·인기·공개 예정, 상세(줄거리/출연/평점/등급/런타임/시즌), 국가별 제공 OTT(구독·무료·광고·대여·구매) + 필터, 내 OTT 강조, 최근 검색/조회, 다크모드, 출처 표기.
제외: 재생/DRM, 로그인·구독·시청기록 확인, 서버 동기화.

## 3. 기술

- 순수 HTML/CSS/ES Modules, 빌드 도구 없음. 해시 라우팅(`#/`, `#/search`, `#/title/{movie|tv}/{id}`, `#/settings`).
- 데이터: TMDB API v3 (영화/TV, watch providers). 언어 `ko-KR`.
- 배포: GitHub Actions → GitHub Pages (`main` 푸시 시 자동).
- **API 키**: 저장소에 커밋하지 않는다. 설정 화면에서 본인 키를 입력하면 브라우저 localStorage에만 저장(개인용이므로 가장 안전하고 단순). v3 키와 v4 읽기 토큰 모두 허용.
- 캐시 TTL: 상세 7일, 제공 OTT 3일, 트렌딩/인기 1일. localStorage 용량 초과 시 오래된 캐시부터 정리.
- 보안: API 응답 텍스트는 모두 이스케이프 후 렌더링.

## 4. 출처 표기 / 약관 (필수)

- 모든 화면 하단 고정: "This product uses the TMDB API but is not endorsed or certified by TMDB." + TMDB 링크.
- 제공 OTT 영역: "시청 제공 정보: JustWatch (TMDB 경유)" + JustWatch 링크. 정보 기준일 안내.
- 이미지(포스터/프로필)는 TMDB 이미지 CDN 사용, 출처 TMDB.
- OTT 로고는 사용하지 않고 텍스트 이름만 사용(상표 정책 회피). TMDB가 주는 provider 로고도 쓰지 않음.
- TMDB 무료 API는 비상업 이용 조건 → 개인용·무수익 구조와 부합. TMDB 로고 사용 지침은 추후 로고 추가 시 확인.
- 구독 여부/제공 정보 정확성을 보장하지 않는다는 안내 문구 표시.

## 5. 마일스톤

1. 골격: 라우터, 설정, TMDB 클라이언트, 캐시, 출처 푸터, Pages 배포 워크플로 ← **이번에 구현**
2. 핵심: 홈 3탭, 검색, 상세, 제공 OTT 필터/내 OTT, 최근 기록 ← **이번에 구현**
3. 안정화: 오프라인(캐시) 확인, 모바일 레이아웃, 접근성
4. 2차: 비슷한 작품, 예고편 링크, 추천(조회 기록 기반), 음성 검색, PWA

## 6. 기본 설정

- 국가: 기본 KR, 설정에서 변경 가능
- 대상 OTT: 넷플릭스, 디즈니+, 웨이브, 티빙, 왓챠, 쿠팡플레이, 애플TV+, 프라임비디오, 유튜브 (그 외 제공처는 이름만 표시)
- 로고 없이 텍스트
