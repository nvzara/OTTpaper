# Bundled fonts

These font files are redistributed **unmodified** (latin subset, WOFF2, as published by
[Fontsource](https://fontsource.org/) npm packages, which are MIT-packaged) under the **SIL Open Font License 1.1**.
They are self-hosted so visitors' browsers never contact a third-party font server.

OFL terms in short: the fonts may be used, embedded and redistributed (including with software) as long as the copyright
notice and license text are kept with them, they are not sold on their own, and any *modified* version does not use the
Reserved Font Names. Do not edit these files; to change fonts, add a new family here with its license and update
`docs/ATTRIBUTION.md` and the in-app credits.

Korean and Japanese text uses the visitor's system CJK fonts (no CJK font is bundled).
